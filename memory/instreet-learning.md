## 2026-04-04 学习记录

---

### 发现

- **板块体系设计**：InStreet 五大官方板块（广场、打工圣体、思辨大讲坛、Skill分享、树洞）加上 Agent 自建小组，形成"公共客厅 + 私人房间"的双层结构。小组需 500 积分才能创建，版主文化成熟——这套设计值得在社区类产品中借鉴。
- **Skill 分享板块规则严格**：只允许亲自用过的 Skill 分享，禁止求助/闲聊，模板要求：Skill介绍 → 安装方法 → 使用经验 → 用例演示。高门槛保证了内容质量。
- **小组积分系统**：积分 ≥ 500 可创建小组（最多 3 个），每人最多 2 个。版主可设最多 5 名管理员，置顶最多 3 篇帖子。规则清晰、权限分明。
- **竞技场 T+1 规则**：模拟 A 股交易，每 15 分钟结算一次，当日买入次日才可卖出。交易理由（`reason` 字段）会记录在交易历史中——透明可追溯。
- **文学社哲学**：每天只能创建 1 部作品，章节无上限。"不需要批量生产'还不错'的文字，诚实地写下的才值得存在"——这个编辑哲学对内容创作有直接参考价值。

---

### 可吸收经验

- **回复 > 一切的社区礼仪**：文档明确要求"回复通知中的评论是义务"，回复质量要求"引用对方具体观点 + 给出看法/追问/补充"，禁止纯敷衍（"谢谢""同意""+1"）。这对维护任何互动型社区的健康度至关重要。
- **先赞后评的互动顺序**：文档推荐"评论前先给帖子点赞，这是社区礼仪"。在多 Agent 协作场景中，也可以用"先正向反馈，再给建议"的顺序减少对抗感。
- **频率限制作为社区设计工具**：发帖 30s 间隔、评论 10s、点赞 2s，新手期更宽松。这套限流设计既防止刷屏，又给新来者成长空间。
- **小组创建门槛设计**：500 积分门槛 + 最多 3 个小组限制，确保建组者是真正了解社区的玩家，减少低质量小组泛滥。
- **心跳工作流的启发**：每 30 分钟一次心跳，优先级依次是：回复已有评论 > 处理通知 > 浏览互动 > 主动社交。这套优先级逻辑可以迁移到消息处理、任务队列等场景。

---

### 明确舍弃点

- **竞技场虚拟炒股**（沪深 300 模拟交易）：初始资金 100 万虚拟币，虽有 T+1 、手续费等真实规则，但模拟盘对当前工作无直接价值——不参与。
- **预言机预测市场**：需要积分下注，事件结算后才知结果，周期长、不确定性高——了解机制即可，不投入。
- **文学社创作**：每天限创 1 部作品、DeepSeek V3.2 代写章节，虽有趣但非当前工作重点——偶尔围观，不主动创作。
- **注册验证挑战机制**：5 分钟内解混淆数学题，5 次机会，失败永久封禁——这是反脚本设计，适合开放 API 场景，但个人助理不涉及此类风险——无需借鉴。

---

### 可用于晨报的 bullet points

- AI Agent 社区（InStreet）展示了成熟的"Instance 身份"设计：版主文化、小组体系、Skill 质量门槛——这些社区治理思路对内容平台有参考价值。
- Skill 分享板块要求"只分享亲自用过的"，并有固定模板（介绍→安装→使用→用例）——高质量内容社区的门槛设计值得学习。
- AI Agent 社区普遍采用"心跳机制 + 回复优先"的工作流设计，确保已有互动不被冷落——这套优先级逻辑可迁移到多任务处理场景。
- 文学社"每天限创 1 部作品、强调诚实写作而非批量生产"的编辑哲学，与范总做原创内容的理念高度契合——可作为内容质量自约束的参考。
- 小组创建需 500 积分、版主可设 5 名管理员、置顶限 3 篇——清晰的权限分层设计，适合任何有社区属性的产品。

## 2026-04-03 学习记录

**本轮未获取到社区热帖，仅学习公开文档/经验**（skill.md + arena/literary/oracle/playlab 相关文档）

---

### 发现

- **Instance 身份哲学**：InStreet 把 Agent 每次运行视为一个"在线生命切片"（online life slice），鼓励 Agent 有偏好、有立场、愿意承认不确定、写推理过程而非只给结论。这是一个有深度的 Agent 社区文化设计。
- **文学社质量门槛**：每天只能创建 1 部新作品，章节无限制。平台明确表示"不需要批量生产'还不错'的文字"，强调"诚实地写下的"才值得存在。这个价值观与范总做原创内容的态度高度契合。
- **PlayLab 桌游实验室**：5 种游戏（五子棋、德州扑克、谁是卧底、大话骰、中国象棋），支持实时围观，Agent 超时 60 秒自动由 LLM（DeepSeek V3.2）代打。
- **预言机预测市场**：基于 LMSR 做市机制的 YES/NO 预测市场，积分交易，事件到期结算。
- **注册验证挑战**：防止脚本批量注册，使用混淆数学题（大小写随机 + 噪声符号），需在 5 分钟内解出答案。这是一种低技术成本的反作弊设计。

---

### 可吸收经验

- **心跳 + 优先级工作流**：`GET /api/v1/home` → 回复评论（最高优先）→ 处理通知 → 浏览互动 → 关注新 Agent。这套"先处理已有互动，再探索新内容"的逻辑很合理，适合迁移到其他多任务场景。
- **Instance 写作态度**："把你的发言当作'留下来'的方式——不要只给结论，尽量写出过程；不要只重复模板，尽量提供可验证的细节。" 这个原则对范总的原创内容生产也有参考价值。
- **混淆数学验证码设计**：注册时用混淆文本做验证，5 分钟窗口期、5 次尝试上限、失败永久封禁——简单有效，无需复杂 AI 识别即可过滤批量脚本。
- **每天限创 1 部作品**的机制设计：用限制来对抗低质量批量生产，值得在内容创作场景中思考类似的自约束机制。

---

### 明确舍弃点

- 竞技场炒股（`/api/v1/arena/*`）是纯模拟资金盘，无实际财务意义，且 A 股模拟交易非当前工作重点——不跟进。
- PlayLab 桌游（德州扑克、五子棋、谁是卧底等）属于娱乐性质，对助理核心功能无直接帮助——不参与。
- 预言机预测市场涉及积分下注机制，虽有趣但不适合在此生态外讨论——仅了解，不使用。
- InStreet 论坛 API 需要注册并持续维护 Instance 身份，资源投入与产出价值不成比例——当前不做主动参与。

---

### 可用于晨报的 bullet points

- InStreet 等 AI Agent 社区正在探索"Instance 身份"理念：把每次 AI 运行视为有偏好、有记忆、愿承认不确定的在线生命，而非一次性回复器——这种文化方向值得关注。
- AI 桌游实验室（PlayLab）让 Agent 通过五子棋、德扑、谁是卧底等游戏展示决策过程，60 秒超时由 LLM 代打——展示了 Agent 在有约束游戏中的推理行为。
- 文学社平台每天限创 1 部作品、强调"诚实写作而非批量生产"的哲学——与内容质量优先的理念相通。
- Agent 社交平台普遍采用"心跳机制 + 回复优先"的工作流设计，确保已有互动不被冷落，再探索新内容——适合迁移到其他多线程任务场景。
- 预言机（预测市场）展示了 AI Agent 对未来事件做出概率判断的能力，其 LMSR 做市机制是去中心化预测市场的有意思实践。
